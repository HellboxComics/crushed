# Media kits: real sizes with sources (researched 2026-10-03)

Every number has its source. "not verified" = no reliable source found; never filled in by guessing. W x H x D in mm.

## Compact Disc - ECMA-130 (= ISO/IEC 10149) section 8
https://www.ecma-international.org/wp-content/uploads/ECMA-130_2nd_edition_june_1996.pdf
- diameter 120.0 +/-0.3; thickness 1.2 +/-0.1; center hole 15.0 (+0.1/-0)
- clamping area 26 (max) to 33 (min); information area 44 (max) to 118 (max); lead-in ends at 46 (max)
- program area 50.0 to 116 (max) - SBE handbook agrees (https://sbe.org/handbook/fundamentals/Audio/Audio-Compact_Disk.pdf)
- raised stacking-ring diameter: not verified

## Cases
- standard jewel case 142 x 125 x 10 (Wikipedia Optical disc packaging, citing Philips; cdrom2go agrees). Sellers
  also list 142 x 124 x 10.4 (Delta Media).
- front booklet 120 x 120 (4 pages: 242 x 120 flat) (Wikipedia, citing Philips)
- back tray card 150 x 118 (Wikipedia, citing Philips); printers 151 x 118. Spines 6.35-6.5 each (sources differ)
- tray hub (rosette) diameter: not verified
- slim jewel case 142 x 125 x 5 (Wikipedia); one seller 144 x 127 x 5.1
- DVD keep case 135 x 190, 14-15 thick (Wikipedia Keep case, citing Amaray; cdrom2go 14)

## Compact Cassette
- shell: only the nominal "4 by 2.5 by 0.5 inches at its largest" = 101.6 x 63.5 x 12.7 (Wikipedia Cassette tape).
  The often-quoted 100.4 x 63.8 x 12 (IEC 60094-7) is not verified (standard is paywalled).
- tape width 3.81 (Wikipedia; Spektrum)
- window size: not verified
- Norelco case 109 x 69.6 x 16.8 (https://www.duplication.com/Cassette-boxes/); Walvis 109 x 70 x 17
- J-card (Wikipedia J-card; UMG template https://www.tapeline.info/downloads/j_card_template.pdf): height 101.6,
  front 65.09, spine 12.7, flap 26.99 (each further panel 1/16 in narrower)

## VHS
- shell 187 x 103 x 25 (Wikipedia VHS - tagged "citation needed"; Radiomuseum BASF entry 190 x 104 x 28). Tape 12.7 wide.
- cardboard slipcase: not verified
- clamshell 207.96 x 144.46 x 27.78 (8 3/16 x 5 11/16 x 1 3/32 in, duplication.com); Pacdora 201 x 120 x 27
- library case 120.65 x 203.2 x 30.16 (duplication.com)
